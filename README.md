# CRVA tiles

Vector PMTiles for the India CRVA Tool (kushankb/crva). One file per climate hazard indicator; each point carries `hist`, `{ssp}_{period}` and `delta_{ssp}_{period}` (future − 1985–2014 baseline).

Built by `CRVATool/data-pipeline/scripts/05_build_tiles.py` from INDRA-CMIP6 (14-model ensemble, 0.1°).
